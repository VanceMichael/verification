# Vue 注册页面项目

这是一个现代化的 Vue 3 前端注册页面项目，包含手机验证码和邮箱验证码功能，使用 Element Plus UI 库实现美观的界面设计。

## 功能特性

- ✨ **现代化 UI 设计** - 采用渐变配色和卡片式布局，视觉效果出色
- 📱 **手机验证码功能** - 支持发送和验证手机验证码（60秒倒计时）
- 📧 **邮箱验证码功能** - 支持发送和验证邮箱验证码（60秒倒计时）
- 📝 **完整表单验证** - 包含用户名、手机号、邮箱、密码等字段的完整验证
- 💬 **Toast 提示** - 使用 Element Plus 的 ElMessage 提供友好的用户反馈
- 🎨 **响应式设计** - 适配不同屏幕尺寸，支持移动端和桌面端
- 🔒 **密码强度** - 密码至少6位，支持密码显示/隐藏切换

## 技术栈

- **Vue 3** - 前端框架（Composition API）
- **Element Plus** - UI 组件库
- **Vite** - 构建工具
- **JavaScript** - 开发语言

## 页面功能说明

### 1. 用户名
- 长度限制：2-20个字符
- 必填字段

### 2. 手机号码
- 格式验证：11位手机号（1开头）
- 必填字段
- 支持发送验证码（60秒倒计时）

### 3. 手机验证码
- 长度限制：6位
- 必填字段
- 实时字符计数

### 4. 邮箱地址
- 格式验证：标准邮箱格式
- 必填字段
- 支持发送验证码（60秒倒计时）

### 5. 邮箱验证码
- 长度限制：6位
- 必填字段
- 实时字符计数

### 6. 密码
- 长度限制：至少6位
- 必填字段
- 支持密码显示/隐藏切换

### 7. 确认密码
- 必须与密码一致
- 必填字段
- 支持密码显示/隐藏切换

## 设计特点

1. **渐变背景** - 紫色渐变背景，视觉冲击力强
2. **圆角卡片** - 大圆角卡片设计，现代感十足
3. **渐变按钮** - 使用与背景一致的渐变配色
4. **悬停效果** - 输入框和按钮都有优雅的悬停动画
5. **阴影效果** - 卡片和输入框都有柔和的阴影
6. **字体设计** - 标题使用渐变文字，层次分明

## 交互体验

- **实时验证** - 表单字段在失焦时实时验证
- **加载状态** - 发送验证码和提交注册时都有加载动画
- **倒计时** - 验证码发送后显示60秒倒计时
- **成功提示** - 注册成功后显示成功消息并重置表单
- **错误提示** - 表单验证失败时显示明确的错误信息

## 自定义配置

可以根据需要修改以下内容：

- **主题配色** - 在 RegisterPage.vue 中修改渐变颜色
- **验证规则** - 在 rules 对象中修改验证逻辑
- **验证码长度** - 修改 maxlength 属性
- **倒计时时间** - 修改 countdown 初始值
