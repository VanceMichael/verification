# Vue 注册页面

一个现代化的 Vue 3 注册页面，支持手机验证码和邮箱验证码注册功能，具有美观的现代化 UI 设计。

## 功能特性

- 📱 手机注册（支持手机验证码
- 📧 邮箱注册（支持邮箱验证码
- ✨ 现代化的 UI 设计
- 🔒 表单验证
- ⏱️ 验证码倒计时
- 💬 Toast 消息提示
- 📱 响应式设计

## 技术栈

- Vue 3 (Composition API)
- Vite
- CSS3 (动画和渐变

## 项目结构

```
├── src/
```

## 功能说明

### 手机注册
- 支持中国大陆手机号码（+86）
- 6位数字验证码
- 60秒倒计时重发
- Toast 提示发送成功

### 邮箱注册
- 支持标准邮箱格式验证
- 6位数字验证码
- 60秒倒计时重发
- Toast 提示发送成功

### 密码要求
- 长度8-20位
- 必须包含字母和数字
- 密码显示/隐藏切换
- 密码确认验证

### 表单验证
- 实时表单验证
- 错误提示
- 用户协议和隐私政策确认

## UI 设计特点
- 渐变色背景
- 卡片式布局
- 平滑动画过渡
- 响应式设计，支持移动端
- 优雅的图标和交互效果
